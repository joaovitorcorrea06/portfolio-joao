# Study LP Codex Skills

Template inicial para criar landing pages em React com uma camada reutilizável de `skills` e `agents`.

O objetivo deste repositório não é gerar LPs genéricas mais rápido. O objetivo é criar um ponto de partida disciplinado para estratégia, copy, direção visual, motion e implementação.

## Stack

- React
- Vite
- Estrutura base para `skills`
- Estrutura base para `agents`

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Como usar este template

1. Defina oferta, público e objetivo de conversão.
2. Use as skills em ordem estratégica.
3. Só depois entre em design e motion.
4. Implemente em `src/` mantendo as seções separadas.
5. Faça revisão final com foco em clareza, diferenciação e performance.
