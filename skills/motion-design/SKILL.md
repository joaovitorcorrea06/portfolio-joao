# Motion Design

## Purpose
Define motion as part of the storytelling system of the LP, not as a cosmetic afterthought.

## Motion Philosophy
Motion should clarify hierarchy, create pacing and intensify attention. If animation exists only to look expensive, it usually weakens the page.

## Use This Skill When
- Planning reveal behavior for sections.
- Deciding whether motion should be subtle, dramatic or minimal.
- Creating a consistent transition language across the page.
- Reviewing a page that feels static or over-animated.

## Motion Roles
- Orientation: help users understand where to look.
- Emphasis: increase weight of key copy, visuals or CTA.
- Continuity: connect sections into one narrative flow.
- Atmosphere: reinforce brand energy.

## Motion System
- Entry motion
- Scroll-triggered reveals
- Component state transitions
- Background or ambient motion
- Exit or transition behavior between major blocks

## Rules
- Assign a purpose to every animation.
- Keep timing families consistent across the page.
- Use larger motion only for structurally important moments.
- Prefer composition and opacity transforms over expensive layout changes.
- Respect reduced motion preferences.

## Pacing Guidance
- Hero can establish the page's motion language.
- Mid-page motion should support reading, not interrupt it.
- Final CTA motion should increase confidence and urgency without looking aggressive.

## Anti-Patterns
- Every element animating independently.
- Long delays that make the page feel slow.
- Decorative scroll gimmicks with no information value.
- Motion that competes with copy readability.
