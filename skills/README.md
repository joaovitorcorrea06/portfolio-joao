# Skills

These skills are written as reusable operating manuals for landing page projects.

## Recommended Use Order
1. `landing-page-foundation`
2. `brand-positioning`
3. `content-direction`
4. `visual-direction`
5. `motion-design`
6. `gsap-orchestration`
7. `img2threejs`
8. `lp-review`

## Design Intent
The sequence above is designed to keep the project specific to the offer. It starts with strategy, then language, then visual identity, then motion and implementation detail.
