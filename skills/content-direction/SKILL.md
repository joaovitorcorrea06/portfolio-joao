# Conversion Copy

## Purpose
Write copy that makes the landing page more persuasive, more specific and less synthetic.

## Standard
Copy must sound like it belongs to a real offer with a real audience. It should not read like auto-generated marketing filler.

## Use This Skill When
- Writing the first LP draft.
- Refining headline, subheadline and CTA.
- Compressing dense product explanations into persuasive sections.
- Revising copy that feels generic, abstract or repetitive.

## Copy Priorities
1. Clarity before cleverness.
2. Specificity before volume.
3. Credibility before hype.
4. Momentum before completeness.

## Writing Rules
- Prefer concrete nouns and verbs over abstract claims.
- Replace broad adjectives with evidence, mechanism or result.
- Keep headline logic legible on first read.
- Tie benefits to user outcomes, not internal features.
- Use rhythm and emphasis intentionally, not through random short sentences.

## Headline Frameworks
- Outcome + audience + differentiator
- Problem reframed + promise
- Strong point of view + practical payoff
- Mechanism + result

## CTA Rules
- One primary action per LP.
- CTA text should imply value, not just action.
- Avoid weak defaults unless strategically justified.
- Reuse CTA language consistently across the page.

## Section Copy Checklist
- Does the section have one argument only?
- Does it advance the decision?
- Does it reduce confusion, increase desire or remove doubt?
- Can any sentence be replaced by something more specific?

## Anti-Generic Filters
- Remove empty claims like "revolutionary", "innovative" or "best-in-class" unless directly proven.
- Remove feature lists that never connect to user stakes.
- Remove filler transitions and repeated promises.
- Avoid tone that sounds like template-driven startup copy unless that tone is a deliberate brand choice.

## Deliverable Format
```md

## Recommended Direction

## Supporting Subheadline

## Section Copy

## CTA System

## Copy Risks
```
