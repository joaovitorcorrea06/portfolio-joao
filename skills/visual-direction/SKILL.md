# Visual Direction

## Purpose
Create a design direction for the landing page that feels intentional, contemporary and specific to the offer.

## Design Principle
The page should have authorship. Good visual direction is not simply "modern"; it is controlled, coherent and hard to confuse with a default template.

## Use This Skill When
- Starting visual exploration.
- Translating strategic positioning into interface language.
- Choosing typography, color, composition and texture.
- Auditing a page that feels polished but interchangeable.

## Visual Axes
- Tension: restrained vs expressive
- Density: spacious vs information-rich
- Materiality: flat vs tactile
- Tempo: calm vs energetic
- Authority: editorial vs product-led

## Required Outputs
- Design concept statement.
- Type direction.
- Color strategy.
- Layout behavior.
- Card, section and component rules.
- Background and texture guidance.
- Motion role at a systems level.

## Visual System Rules
- Choose one dominant typographic voice and one supporting voice.
- Define why each color exists.
- Establish a strong rhythm for section spacing and transitions.
- Use contrast in scale and composition to create narrative emphasis.
- Avoid neutral filler blocks that contribute no identity.

## Avoid
- Default startup gradients with no relation to the offer.
- Overuse of glassmorphism or shadows without conceptual reason.
- Generic illustration packs used as brand substitutes.
- Component libraries applied without visual editing.
