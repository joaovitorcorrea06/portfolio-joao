# LP Review

## Purpose
Review a landing page with a conversion, design and implementation mindset before release or handoff.

## Review Lens
The page should be evaluated as a system: strategy, copy, design, motion and code need to reinforce the same argument.

## Use This Skill When
- A first version of the LP is complete.
- A redesign risks losing the original narrative.
- Motion or visual experimentation may have introduced noise.
- The page needs a sharper pre-launch pass.

## Review Criteria
- Strategic clarity
- Section order quality
- Copy specificity
- Visual distinctiveness
- CTA clarity
- Motion discipline
- Responsive behavior
- Performance risk
- Implementation maintainability

## Red Flags
- The hero looks premium but says little.
- Mid-page sections repeat benefits with different styling.
- Motion competes with reading.
- The page relies on buzzwords more than evidence.
- The visual system feels borrowed rather than authored.
