# LP Template Playbook

## Goal
Use this repository as a repeatable but non-generic starting point for landing page projects.

## Operating Model
The repository should behave like a small system:
- `skills/` define how to think and decide.
- `agents/` define who owns each layer of the work.
- `src/` holds the implementation.

## Recommended Workflow
1. Define the offer, audience and conversion goal.
2. Run `landing-page-foundation`.
3. Run `brand-positioning`.
4. Draft copy with `content-direction`.
5. Define the design system with `visual-direction`.
6. Define motion rules with `motion-design`.
7. Use `gsap-orchestration` only when timeline-based motion is justified.
8. Use `img2threejs` only for a signature visual moment.
9. Run `lp-review` before final polish or launch.

## Quality Bar
- The page must feel authored.
- The motion must feel disciplined.
- The copy must sound specific.
- The design must not depend on category clichés.
- The code must remain easy to iterate on.

## Anti-Template Reminder
If the same structure, tone and visuals could be reused unchanged for five unrelated products, the work is still too generic.
