# Agents

This folder defines reusable roles for landing page work. Use the agents together rather than as isolated personas.

## Recommended Sequence
1. `strategy-agent`
2. `copy-agent`
3. `design-agent`
4. `motion-agent`
5. `frontend-agent`
6. `review-agent`

## Rule
Do not let implementation start before strategy and positioning are minimally stable. Most generic LP output comes from reversing that order.
